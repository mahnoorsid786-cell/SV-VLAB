| Statement ID | Statement Name        | Description                                                                                 | Entry Condition                                                                                       | Exit Condition                                                                          |
| ------------ | --------------------- | ------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| **S1**       | **IDLE**              | The robot is at the warehouse and waits for a new delivery request.                         | Robot reaches the warehouse and becomes available for a new request.                                  | A delivery request is received.                                                         |
| **S2**       | **NAVIGATING**        | The robot moves toward the destination while monitoring its surroundings and battery level. | A delivery request is received while the robot is IDLE, or an obstacle has been successfully avoided. | Destination is reached, an obstacle is detected, or the battery becomes critically low. |
| **S3**       | **AVOIDING_OBSTACLE** | The robot temporarily stops normal navigation and performs obstacle-avoidance actions.      | An obstacle is detected while NAVIGATING.                                                             | The obstacle is successfully avoided.                                                   |
| **S4**       | **DELIVERING**        | The robot performs the package delivery at the destination.                                 | The robot reaches the destination.                                                                    | The package is successfully delivered.                                                  |
| **S5**       | **RETURNING**         | The robot travels back to the warehouse after completing or stopping the delivery journey.  | Package is successfully delivered, or the battery becomes critically low during navigation.           | The robot reaches the warehouse.                                                        |
